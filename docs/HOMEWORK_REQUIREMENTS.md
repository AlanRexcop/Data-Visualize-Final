# Data Visualization Final Project Requirements

**Course:** Data Visualization
**Context:** Vietnam

## 1. Project Content
- Present a data visualization project application using a **Dashboard** for data analysis.
- The context of the data must be **Vietnam**.
- Groups will present their projects during an oral examination session.

## 2. Data Requirements
- **Authenticity:** Data must be real data related to Vietnam.
- **Independent Variables:** Minimum of **7 independent variables**.
- **Volume:** Minimum of **2000 rows**.
- **Relevance:** Total data related to Vietnam must be over **50%** of the dataset.

## 3. Evaluation Criteria (8 Standards)

### 1. Reliable Data Sources
- Combine and use trustworthy data sources.
- Ensure transparency in how the data was provided.
- Check for any omissions or gaps in the data processing workflow.

### 2. Purpose-Driven Visualization
- Visualization must reflect its specific purpose.
- Example: Bar charts for comparison, line charts for time-series trends.
- Consider if the visualization is appropriate for the target audience.

### 3. Clarity and Understanding
- Visualizations should communicate messages clearly and be easy to understand.
- Charts and graphs should be designed so viewers can quickly perceive and understand the information.

### 4. Integration and Connectivity
- If using multiple charts or graphs, ensure there is a logical link and integration between them.
- The relationship between different parts of the visualization should be made clear.

### 5. Interaction and Navigation
- Interaction (if any) should be logically integrated for viewers to explore the data.
- The navigation system should be built for ease of use.

### 6. Attractive Design
- Graphic design and colors should make the visualization attractive and attention-grabbing.
- Use colors meaningfully and avoid "color overload."

### 7. Data Analysis
- Visualizations should show changes and trends over time (if applicable).
- Relationships between variables must be clear.
- Provide relevant conclusions and "storytelling."

### 8. AI Integration
- Demonstrate the use of AI in the **Design** and **Operation** of the project.
