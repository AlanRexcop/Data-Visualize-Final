# Conda Environment Configuration: Data_Lab1

This file documents the environment used for the Vietnam CPI data transformation and analysis.

## Environment Name
- **Name:** `Data_Lab1`

## Essential Packages for this Project
These packages are critical for the data processing (`transform_data.py`) and the visualization prototypes (`analysis_prototypes.ipynb`).

| Package | Version | Purpose |
| :--- | :--- | :--- |
| **pandas** | 2.3.3 | Data manipulation, melting, and CSV export. |
| **numpy** | 2.2.6 | Numerical operations and NaN handling. |
| **matplotlib** | 3.10.6 | Core plotting library for visual prototypes. |
| **seaborn** | 0.13.2 | Advanced statistical visualizations (Heatmaps, Boxplots). |
| **nbformat** | 5.10.4 | Programmatic generation of the Jupyter Notebook. |

## Machine Learning & Advanced Statistics
The environment is also equipped for predictive modeling and advanced statistical analysis.

| Package | Version | Purpose |
| :--- | :--- | :--- |
| **scikit-learn** | 1.7.2 | Machine learning algorithms (Clustering, Regression). |
| **statsmodels** | 0.14.5 | In-depth statistical modeling and time-series analysis (e.g., ARIMA). |
| **xgboost** | 3.2.0 | High-performance gradient boosting for forecasting. |

## Environment Capabilities
The environment is fully configured for:
1. **Data Engineering:** Handling large CSV files and performing complex feature engineering.
2. **EDA:** Generating high-quality statistical charts.
3. **Notebook Generation:** Creating ready-to-use `.ipynb` files for handover.
