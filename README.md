# Vietnam CPI Analytics - Project README

## 🇻🇳 Project Overview
This project analyzes 22 years of Vietnam's Consumer Price Index (CPI) data (2002-2024). It consists of a data processing pipeline and a custom-built **AI Analyst Module** designed to meet strict academic standards for Data Visualization.

## 📁 Project Structure
- `analysis/`: Contains the refined datasets (`CPI_final_for_powerbi.csv`).
- `data/`: Contains the raw GSO data (`Long_cleaned.csv`).
- `output/`: Processed data and AI-generated audit logs/plots.
- `scripts/`:
  - `ai_analyst_app.py`: The main Streamlit AI Dashboard.
- `docs/`: Full project documentation, requirements, and environment details.

## 🚀 Getting Started

### 1. Prerequisites
- [Anaconda/Miniconda](https://www.anaconda.com/) installed.
- A Gemini API Key (Get a free one at [Google AI Studio](https://aistudio.google.com/app/apikey)).

### 2. Setup Environment
```powershell
# Create/Activate your environment
conda activate Data_Lab1

# Install dependencies if not already present
pip install streamlit google-genai pandas matplotlib seaborn python-dotenv
```

### 3. Run the AI Analyst Module
```powershell
streamlit run scripts/ai_analyst_app.py
```

## 🤖 AI Integration Standards
This module was developed following the **"Human-in-the-Loop"** principle:
- **Transparency:** Every line of code generated by the AI is displayed for review.
- **Control:** The user must manually edit/approve code before execution.
- **Audit:** All interactions, thinking processes, and manual edits are logged to `output/audit_log.json`.
- **Local:** All data processing and code execution happens on your local machine.

## 📊 Key Findings
- **The Tet Effect:** Annual inflation peaks in Jan/Feb due to Lunar New Year.
- **Crisis Years:** 2008 and 2011 identified as historical volatility peaks.
- **Leading Indicators:** Transport costs and Gold prices drive most consumer goods fluctuations.
